# Brand — Audio Harbor

## Positioning

A simple, beautiful local audiophile player for macOS and iOS.

**Promise:** Open folder → hear truth. Fewer controls, better defaults, exceptional playback.

**Gap vs. competitors:** Pine Player Pro is powerful but crowded. This product ships less surface area and a cleaner path from library to DAC.

| Principle | Meaning |
|---|---|
| One job | Play local high-res audio correctly |
| Honest quality | Prefer bit-perfect over marketing upsampling |
| Calm UI | Brand + library + now playing — nothing else competing |
| Shared soul | Same product language on Mac and iPhone; Mac leads on DAC depth |

**Visual direction (current scaffold):** Dark, quiet atmosphere; warm amber accent; serif display for the brand mark; no purple glow / AI-default look.

### Audiophile Harbor — detail

| Factor | Assessment |
|---|---|
| Exact product/app collision | Keine starke „Audiophile Harbor“ App/TM im Spotcheck |
| Near neighbors | MusicHarbor (Store); Gig Harbor Audio / Harbor Audio-Video (Retail) — gleiche wie bei Audio Harbor |
| Word „Audiophile“ | Sehr beschreibend für Hi-Fi-Software. Viele AUDIOPHILE-*-Filings sind dead/cancelled; allein schwer schützbar (descriptive) |
| Markenstärke | Schwächer als **Audio Harbor**: Examiner kann „Audiophile“ als bloß beschreibend sehen → Disclaimer oder 2(e)(1)-Risiko |
| Aussprache / Länge | Länger, etwas „Marketing-Flyer“; klar, aber weniger elegant |
| SEO | Gut (Suchintent), aber generisch — schwer, sich gegen „audiophile player“-Content durchzusetzen |

**Verdict:** Collision-mäßig okay; **als Marke und Brand schwächer als Audio Harbor**. Wenn Kategorie im Namen sein soll: eher **Audio Harbor** + Store-Untertitel *Local audiophile player*.

**Avoid:** „Audiophyl Harbor“ (Tippfehler-Look; wirkt unabsichtlich falsch, hilft Marke kaum).

### Audio Harbor — detail

| Keine starke exakte USPTO-Hit für **„Audio Harbor“** als Player-Marke im Spotcheck | Gut |

**Verdict:** Vorläufig **eine der besten Shortlist-Optionen**. Deep-check nötig wegen MusicHarbor + regionalen Harbor-Audio-Händlern, aber kein harter Drop wie Aural / Audio Reality.

## Naming guidelines

**Avoid**
- Generische AI-Namen (*SonicAI*, *Audiofy*, *HarmonyHub*)
- Zu enge Tech-Akronyme (*DoPPro*)
- Nähe zu bestehenden Marken (*Pine*, *Roon*, *Audirvana* / *Audir…*)

**Prefer**
- Kurz (1–2 Silben ideal)
- International aussprechbar
- Domain + App Store + Bundle-ID machbar
- Kein erklärungsbedürftiges Feature-Jargon als Markenname

## Voice & messaging

| Do | Don’t |
|---|---|
| Local-first, honest about Mac vs iOS DAC limits | Claim “768 kHz magic” as the hero |
| Bit-perfect by default | Feature maze, converter suite in the main path |

**Example lines**
- Local. Bit-perfect. Calm.
- Your folders. Your files. No cloud required.
- Bit-perfect by default. Features earn their place.
- Start with Shared. Exclusive when your DAC is ready.
