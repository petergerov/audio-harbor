The path to the DAC

Three ways out. Start with Shared.

Audiophile software loves jargon. We don’t. If you are unsure, leave Shared on — that is the daily driver, on every device.

Shared
◇

Everyday listening — recommended

Plays like any other app. Calls, YouTube, speakers, Bluetooth, AirPlay still work. This is the default, and the only honest path for anything that is not a dedicated DAC.

Exclusive
◎

Bit-perfect into a USB DAC

Mac only, with an external DAC. Audio Harbor takes over the DAC so the file’s sample rate stays as-is. Other apps go silent; set the volume on the DAC. DSD files are converted to PCM.

DoP
☾

Exclusive, plus real DSD

Mac only. Everything Exclusive does — and DSF, DFF, and SACD ISO (including DST) reach the DAC as real DSD via DoP. Pick it only if your DAC plays DSD. No separate DSD setting: the output mode decides.

No external DAC connected? Exclusive and DoP grey out and Shared takes over — plug the DAC back in and your choice returns on its own. Pick the device in Settings — music to the DAC, system sounds stay on the Mac speakers — and switch device or mode while the song plays. Effects on the rack keep the DAC exclusive at the file’s rate (Exclusive · FX), but processed sound is not bit-perfect — only the empty rack is, and we will not pretend otherwise. More in the FAQ.

Audio Units

AU plugins. In the player.

Audio Harbor is a host. Load the AU and AUv3 effects you already use in Logic, GarageBand, or AUM — as inserts on the Deck, while the record plays.

Mac

AU and AUv3

Any stereo Audio Unit effect — AUv3 extensions and classic AU components. The same units other Apple hosts see. Add from the rack, open the plugin’s own editor, keep the settings after quit.

Out of process

Crash-safe

AUv3 effects run outside the player. Classic AUs that are not sandbox-safe — most commercial ones — run in macOS’s own Audio Unit host, not inside Audio Harbor. A plugin that misbehaves takes itself down, not your listening.

Honest path

Exclusive · FX

With Exclusive or DoP on a DAC, a loaded rack keeps the DAC to itself at the file’s sample rate — no system mixer, no macOS resampling. Only the plugin changes the sound. Clear the inserts when you want the DAC bit-perfect or DSD via DoP again.

＋

Add from the Deck

The rack sits under Now Playing. Search the installed units, drop one in, reorder, bypass. No separate “FX app.”

◻

The plugin’s own UI

Edit opens the AU view — knobs, graphs, whatever the vendor shipped. Not a generic parameter list unless that is all the unit has.

◎

Settings stay

Chain, bypass, and plugin state are stored with the app. Quit and reopen: the same EQ, the same room correction.

Stereo inserts only. Some vendor AUs expect a DAW host and will refuse a player graph — we drop those rather than crash. Waves-class units are the usual example.

Formats

What it will play

The files on your disks — not a converter suite in the main path.

PCM, as written

FLAC · ALAC · WAV · AIFF · AAC/M4A · MP3. Gapless where the format allows. Exclusive keeps 24-bit PCM bit-perfect on Mac.

DSD, with a label

DSF, DFF, and SACD ISO stereo — including DST-compressed discs. Output DoP sends real DSD; Shared and Exclusive convert to PCM. The path says which one you are on.

Not in the main path

No converter suite, no 768 kHz upsampling theatre, no Qobuz/Tidal. Those dilute the local-first promise.

What the badge is for

The Deck shows the format and the path — Shared, Exclusive, DoP, Exclusive · FX, or Shared · FX — so you are never guessing what left the app.
